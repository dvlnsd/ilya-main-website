Сумбава

Рифовые волны, открытые побережья и свобода выбирать лучший ритм дня.

Остров

Разные берега, разные волны

Сумбава предлагает несколько зон для серфинга. Экспозиция побережья, ветер и направление свелла формируют выбор на каждый день.

Океан

Мобильность расширяет выбор

Перемещения между зонами позволяют точнее подбирать размер и форму волны для текущих задач группы.

Илья ведёт планирование по прогнозу и сопровождает участников в воде.

Формат

Для серферов с устойчивой базой

Формат подходит людям, которые уверенно ловят волны и готовы знакомиться с рифовыми спотами разного характера.

  • Группа до пяти человек
  • Несколько зон для серфинга
  • Ежедневная работа с прогнозом
